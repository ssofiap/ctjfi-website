# CTJFI Church Website

[![CI](https://github.com/ssofiap/ctjfi-website/actions/workflows/ci.yml/badge.svg)](https://github.com/ssofiap/ctjfi-website/actions/workflows/ci.yml)

### Overview
The CTJFI website provides a welcoming online presence for Come to Jesus Fellowship International. Visitors can learn about the church, find service times and directions, explore the community's mission, and watch the livestream.

### Features
- **Welcome Page**: Introduction to CTJFI, its mission, community, and worship.
- **Service Times**: Interactive calendar for upcoming services.
- **Visit Us**: Church address, public transport information, map, and directions.
- **Livestream**: Direct link to the CTJFI YouTube channel.
- **Image Carousel**: Visual highlights from the church community.

### Technology Stack
- **Framework**: Next.js 16 with React 19
- **Language**: TypeScript
- **Styling**: Tailwind CSS 4
- **UI and Utilities**: Radix UI, Lucide React, Embla Carousel, date-fns, and React Day Picker
- **Quality**: ESLint with the Next.js configuration
- **Deployment**: Vercel-compatible Next.js application

### Development
From the repository root, run:

```bash
cd frontend
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site. Use `npm run build` to create a production build and `npm run lint` to check the code.
